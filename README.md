# Hometown

**[Live Demo](https://seanwong17.github.io/hometown/)** · [源码仓库](https://github.com/SeanWong17/hometown)

基于 Three.js 和 Vite 的房屋三维模型。模型由仓库中的 JavaScript 程序生成，可在浏览器查看布局、家具、门窗和吊顶，并进行第一人称漫游。

## 功能

- 立体、俯视和漫游视角；可切换墙体、地面、房间标签与尺寸标注。
- 按使用频率选择七组空间：客厅、西卧室、东卧室、厨房、洗漱间（含洗澡间）、阳台、杂物间。杂物间包含大、小两间。
- 浏览器内导出当前视图 PNG，或导出包含墙体、地面、家具和吊顶的 GLB 模型。
- 桌面和手机浏览器均可使用；采用相对资源路径，支持部署在静态站点的子目录。

## 本地运行

需要 Node.js 18 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 `http://localhost:5173/`。生成并预览静态站点：

```sh
npm run build
npm run preview
```

构建结果位于 `dist/`。拉取请求会运行构建检查；推送到 `main` 后，GitHub Actions 会构建并部署到 GitHub Pages。

## 操作

- 立体视角：拖动旋转、滚轮缩放、右键拖动平移；触屏使用单指旋转、双指缩放和平移。
- 漫游视角：选择房间后点击“进入”，使用 WASD、方向键或屏幕方向按钮移动，拖动画面转头。可以沿门洞走到其他房间。点击“立体”或“俯视”退出漫游。
- “导出当前视图”保存 PNG 截图；“导出模型（GLB）”保存完整房屋模型，可在 Blender 等支持 glTF 2.0 的软件中打开。导出模型不受当前显示开关影响。

## 维护模型

- `src/model.js` 定义房间、墙线、开口、家具位置及漫游碰撞。房间导航顺序由 `roomNavigation` 定义。
- `src/main.js` 负责场景、相机、控制和导出。`src/` 内其他模块绘制各房间陈设。
- `floor-plan.png` 为原始参考图，页面中的“原始户型图”按钮可以查看。

模型依据参考图和手工核对制作。尺寸与面积均为近似值，不可作为施工测绘数据；原图中的个别面积标注与模型修正值可能不同。
